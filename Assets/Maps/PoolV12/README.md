2층, 계단, 풀과 침강부, 밸브·배수구·출구·스폰 좌표는 유지합니다. 배수구는 수면 아래 Y=-3.5입니다. 문 개구부 높이2.5m, 비충돌 응급침대 임시 위치, 숨긴 지붕 등 기존 블록아웃 한계는 유지합니다. 게임 시스템·서버·플레이어·수영 기능은 없습니다.

이 팀 프로젝트 복사본에는 맵 씬과 런타임 에셋이 포함됩니다. Create Exact Map, Validate Saved Map, Replace Selected Module Visual 편집기 도구는 독립 검토 프로젝트 `Tools/PoolBlockoutPreview`에 남아 있습니다.

## Git 및 팀 통합 주의
v1.1 씬과 에셋은 보존하며 v1.2는 별도 경로와 GUID를 사용합니다. 팀이 이전 씬에 직접 연결한 네트워크 객체·상호작용 참조는 새 씬으로 자동 이동되지 않습니다. 삭제된 방/문 ID를 쓰는 시스템은 SZ/AID와 남은 문에 맞춰 갱신해야 합니다. 새 Prefab과 meta도 함께 전달해야 합니다.

이 공유 프로젝트는 2026-10-20 Unity6000.5.4f1 / URP17.5.0 / InputSystem1.19.0으로 변환·검증했습니다. 초기 제작 버전은6000.3.10f1입니다. 팀 루트와 Editor 버전은 같지만 프로젝트 설정을 통째로 덮어쓰지 말고 별도 브랜치/PR에서 렌더링·게임 시스템 통합을 확인해야 합니다. Tools 아래 독립 프로젝트 공유만으로 팀 게임에 통합되는 것은 아닙니다.

## 검증 한계
좌표·충돌·면적·이동 연결·계단·수심·문 위치와 문 모서리~A 직선거리 검증을 수행합니다. A↔D 동시 감시 여유1.9m, 벽·층간·수면 음향 차폐, 대각선 시야46m의 게임 영향은 구현된 음향/플레이어 시스템이 없어 재현 검증하지 않습니다. B1~B3 실제 플레이 확인은 팀에서 필요합니다.
