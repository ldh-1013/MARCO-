## 정정 1 — A↔C 경로 거리: **64.1m 확정**

### 판단 근거

66.5가 나온 스크립트를 찾을 필요 없다. **존재하지 않는다.**

지시서 표 안에서 자기모순이기 때문이다. 계단 비용을 14.4m로 잡아야 A↔C = 66.5가 되는데, 같은 표의 나머지 C 쌍 3개는 전부 **계단 12m 기준 값**이다.

| 쌍 | 지시서 값 | 계단 12m 기준 | 계단 14.4m 기준 |
|---|---|---|---|
| A↔C | 66.5 | 64.1 | **66.5** |
| B↔C | 41.5 | **41.5** | 43.9 |
| C↔D | 30.5 | **30.5** | 32.9 |
| C↔E | 30.7 | **30.7** | 33.1 |

한 표 안에 계단 비용이 두 개일 수는 없다. A↔C 행만 잘못 전사된 것이다. **디스크의 스크립트가 정본이다.**

### 반영할 값

```markdown
| A ↔ C | 43.0m | **64.1m** | 12.8초 | 8.5초 | 12.1초 |
```

검산: `64.1 ÷ 5.0 = 12.8` / `64.1 ÷ 7.5 = 8.5` / `64.1 ÷ 5.30 = 12.1`

### 66.5가 들어간 4곳 전부 교체

| 위치 | 현재 | 교체 |
|---|---|---|
| §10.2 거리표 A↔C 행 | 66.5m, 13.3초, 8.9초, 12.5초 | **64.1m, 12.8초, 8.5초, 12.1초** |
| §10.2 인용문 | `C 관련 3쌍(30.5~66.5m)` | `C 관련 **4쌍**(30.5~64.1m)` ← 쌍 수도 정정(비차단 #2) |
| §10.2-1 검증 결과 | `경로 30.5~66.5m` | `경로 30.5~64.1m` |
| §10.2 왕복 부담 문단 | `최장 구간(A↔C 66.5m)` | `최장 구간(A↔C 64.1m)` |

**영향 없음을 확인할 것**: 37.5m 초과 4쌍(A↔C·A↔D·A↔E·B↔C) 판정, 최장 구간이 A↔C라는 점, 10/10 합격 — 전부 유지된다.

## 정정 2 — 칸막이 서술 하향

### 판단 근거

"칸막이 제거 시 A↔B에 동시 감시 지점 3개"는 재현되지 않았다. **스크립트가 0개라고 답하면 그것이 사실이고, 그 주장은 근거 없는 문장이다.** 검증된 요소와 검증 안 된 요소를 같은 표에 "결정적"으로 나란히 두면 표 전체를 믿을 수 없게 된다.

반면 기계실 남쪽 출입구 1개는 재현됐다(제거 시 A↔B 22.7m, 불합격 1쌍). **이쪽만 남긴다.**

### 2-1. §10.1 출구·개구부 표

```markdown
| 기계실–풀 홀 칸막이 | x=40, y=13~20 | 여유 확보용 권장 요소. 제거해도 10쌍 검증은 통과한다 |
```

`**10.2-1 검증 통과에 필수**` 문구를 삭제한다.

### 2-2. §10.2-1 "검증에 결정적인 지형 요소" 블록 교체

````markdown
**검증에 결정적인 지형 요소 — 스크립트로 재현 확인** [v0.4]

| 요소 | 제거 시 | 판정 |
|---|---|---|
| **기계실 출입구 1개(남쪽 (45,5))** | A↔B 경로 32.7m → **22.7m**, 동시 감시 지점 1개 발생 → **불합격 1쌍** | **필수** |
| 기계실–풀 홀 칸막이 (x=40, y=13~20) | 불합격 0쌍 — A↔B 동시 감시 지점도 0개 | **권장**(여유 확보) |

**기계실에 두 번째 출입구를 내면 6.1절 "퇴로 없음"이 깨질 뿐 아니라 10.2-1 검증도 무너진다.** 이 문 하나가 A↔B의 합격/불합격을 가른다.
````

### 2-3. §10.2 인용문에서도 같은 톤으로

`이 문 하나가 A↔B 검증의 합격/불합격을 가른다` — **유지**(재현됨).
칸막이를 언급하는 문장이 있으면 "권장 요소"로 낮춘다.

### 2-4. 보고 시 함께 제출할 것

칸막이 제거 상태에서의 **A↔B 경로 거리 실측값**을 보고하라. 조건①(30m)의 여유가 얼마나 남는지가 "권장" 등급의 근거가 된다. 30m를 밑돌면 권장이 아니라 필수로 되돌려야 한다.

## 정정 3 (비차단 #1) — 더블체크 7의 검산식

| | |
|---|---|
| 잘못된 식 | `14.4 × 2 × 0.5^n` → 28.8 / 14.4 / 7.2 / 3.6 ❌ |
| **올바른 식** | `14.4 × (1 + 0.5^n)` → 28.8 / 21.6 / 18.0 / 16.2 ✅ |

**유도**: 감시 지점 P가 두 밸브 사이 어디에 서든, 벽 n장은 양쪽으로 갈린다(a + b = n). 조건은 `d1 ≤ 14.4 × 0.5^a` 이고 `d2 ≤ 14.4 × 0.5^b`. 합 `d1 + d2`가 최대가 되는 것은 **한쪽이 0장일 때**, 즉 P가 한 밸브에 붙어 설 때다. 따라서 임계 = `14.4 × (0.5^0 + 0.5^n)` = `14.4 × (1 + 0.5^n)`.

**표의 값 4개는 원래 맞았다.** 더블체크 항목의 검산식만 틀렸다. 더블체크 7을 위 식으로 교체하고, **n=4 까지 검산하라**(정정 4에서 필요).

## 정정 4 (비차단 #3) — C↔D를 "합격 사례"에서 "최대 위험 쌍"으로 승격

### 판단 근거

원 지시서는 C↔D를 *"벽 한 장만 끼워도 21.6m로 떨어진다 — C↔D가 합격하는 이유"* 로 썼다. **정반대다.**

| 항목 | 값 |
|---|---|
| C↔D 사이 차폐 | 벽 2장 + 층간 바닥(벽 2장 상당) = **4장 상당** |
| 임계 거리 | `14.4 × (1 + 0.5⁴)` = `14.4 × 1.0625` = **15.30m** |
| 실제 직선 거리 | **15.6m** |
| **여유** | **0.30m** |

10쌍 중 가장 빠듯하다. **벽 하나만 빠져도 임계가 16.2m로 올라가 즉시 불합격이다.**

### 4-1. §10.2-1 임계표에 4장 행 추가

```markdown
| 두 밸브 사이 벽 | 동시 감시가 가능해지는 밸브 간 거리 |
|---|---|
| 0장(같은 개활 공간) | 28.8m 이하 |
| 1장 | 21.6m 이하 |
| 2장 | 18.0m 이하 |
| 3장 | 16.2m 이하 |
| **4장 상당**(벽 2 + 층간 바닥) | **15.3m 이하** |
```

### 4-2. 그 아래 설명 문단 교체

````markdown
**즉 진짜 제약은 거리가 아니라 "두 밸브를 같은 개활 공간에 두지 않는 것"이다.** 벽을 한 장만 끼워도 임계가 28.8m → 21.6m로 떨어진다.

> **⚠ C↔D가 10쌍 중 가장 위험하다.** 직선 15.6m에 차폐 4장 상당(벽 2 + 층간 바닥)으로 임계 15.3m —
> **여유가 0.30m뿐이다.** 그레이박스에서 두 구역 사이 벽이 하나라도 빠지면 임계가 16.2m가 되어
> 즉시 불합격한다. **블록아웃 직후 이 쌍부터 실측 검증하라.**
> 미달 시 1순위 조정은 밸브 D를 약품창고 북쪽으로 옮기는 것이다(C에서 멀어진다).
````

## 정정 5 (비차단 #4) — 왕복 부담 근거 확장

### 판단 근거

원 지시서는 "도망자 수 ≥ 요구 개방 수"만 근거로 삼아 **태그로 인원이 줄어 그 부등식이 깨지는 경우**(예: 4인 게임에서 1명 태그 → 도망자 2명이 밸브 3개)를 빠뜨렸다.

이 경우에도 결론은 유지되지만 **근거가 다르다.** 진행도 감쇠(0.10/s)는 **회전 중인 밸브**에만 적용되고, 이미 열린 밸브는 §6.1-2 **역류 타이머 180초** 동안 유지된다.

최악 시나리오 산출 — 최장 편도 A↔C 64.1m:

| 구간 | 값 |
|---|---|
| 질주 5초(스태미나 상한) | 37.5m |
| 소진 페널티 3초 (5.0 × 0.8 = 4.0 m/s) | 12.0m |
| 잔여 14.6m 걷기(5.0 m/s) | 2.9초 |
| **이동 합계** | **10.9초** |
| 도착 후 회전 | 8.0초 |
| **총 소요** | **18.9초** |
| 역류 유예 | **180초** |
| **여유** | **161초** |

### 5-1. §10.2 왕복 부담 문단 교체

````markdown
> **왕복 부담 검증 [v0.4]**: 진행도 감쇠 0.10/s 하에서 최장 구간(A↔C 64.1m)을 왕복해야 한다면 작업이 성립하지 않는다. 두 단계로 확인한다.
>
> **① 정상 인원** — 6.2절 인원별 표에서 **도망자 수 ≥ 요구 개방 수**가 전 구간 성립한다(3인 2:2 / 4인 3:3 / 5인 4:3 / 6인 5:3). 1:1 배치가 가능해 왕복이 발생하지 않는다.
>
> **② 태그로 인원이 줄어 ①이 깨진 경우**(예: 4인에서 1명 태그 → 2명이 3개) — 이때는 편도 이동이 한 번 생긴다. 그러나 **감쇠는 회전 중인 밸브에만 적용되고, 이미 열린 밸브는 6.1-2절 역류 타이머 180초 동안 유지된다.** 최장 편도 64.1m는 질주 5초(37.5m) + 소진 페널티 3초(12m) + 걷기 2.9초(14.6m) = **10.9초**, 회전 8초를 더해 **18.9초**다. 180초 대비 여유 161초로 성립한다.
>
> 도망자가 1명으로 줄면 6.5절 최후 생존자 페이즈로 전환되어 밸브 왕복 자체가 사라진다. **밸브 간 거리에 상한 제약은 필요 없다.**
````
