## 0. 왜 이 작업이 필요한가 — 모순의 내용

§6.5-3은 최후 생존자 페이즈의 공정성 전체를 **한 문장**에 걸고 있다.

> 수심 3.5m, 태그 반경 1.2m이므로 술래는 수면에서 배수구에 닿을 수 없다.

그런데 §6.5-2는 배수구를 **2개소**에 두고 그중 하나가 **유아풀**이다. 유아풀은 문서 전체에서 일관되게 얕다.

| 근거 | 내용 |
|---|---|
| §10.1 | 유아풀 존 — 밸브 E**(얕은 수중)** |
| §6.1 밸브 표 | E = **수중(얕음)**, 진입 0.5 / 부상 0.5 |
| B와 비교 | B는 3.5m에 진입 1.5 / 부상 1.5 — **시간비 3:1** → 수심 약 1.2m 추정 |
| 부록 A | **배수구 1만** "수중 3.5m, 잠수 필수". 배수구 2의 수심은 문서 어디에도 없다 |

**결과**: 서버가 배수구 2를 고르면(확률 50%) 술래는 걸어 들어가 서 있기만 하면 된다. 태그 반경 1.2m와 추정 수심 1.2m이 정확히 겹친다. §6.5-3의 "술래에게 잠수를 주지 않는다"가 무의미해지고, **도망자 1명에게 남은 유일한 승리 경로가 라운드의 절반에서 사라진다.**

프로토타입의 목적이 "이 게임이 재미있는가"를 확인하는 것인데, 이 상태로는 **엔드게임의 절반을 테스트할 수 없다.**

### 채택안 — 유아풀 배수구 지점만 국소 침강부(sump)로 판다

레벨 지오메트리 1개소의 수심 값이다. 규칙·상태기계·`SoundType` 어느 것도 늘지 않으므로 §3.3에 걸리지 않는다. 실제 수영장도 얕은 유아풀에 배수 침강부는 깊게 판다.

부수 효과로 **밸브 E의 정체성이 선명해진다** — 같은 물에서 밸브는 0.5초에 들어갔다 나오는데 배수구는 완전 잠수를 요구한다. "얕아서 안전한 물"이 페이즈 전환과 함께 "깊어서 위험한 물"로 뒤집힌다.

## 1. 수평 거리 제약 — §6.5-3 논거의 빠진 절반

§6.5-3의 논거에는 **수평 방향이 없다.** 배수구가 물가에 붙어 있으면 술래는 **마른 바닥에 선 채로** 부상하는 도망자를 태그한다. 깊이로 막은 것을 거리로 뚫는 것이다.

따라서 수심 3.5m와 짝을 이루는 수평 제약을 명시한다.

| # | 제약 | 기준 | 근거 |
|---|---|---|---|
| **D-1** | 배수구 ↔ **육상(물 밖) 최단 거리** | **3.0m 이상** | 태그 반경 1.2m + 물가에서 한 걸음 내디딘 여유 1.8m. **술래가 반드시 물에 들어가야 닿는다** |
| **D-2** | 배수구 ↔ 같은 구역 밸브 | **3.0m 이상** | 상호작용 프롬프트 분리(구현 제약). 겹치면 E 홀드 대상이 모호해진다 |

**D-1이 핵심이다.** D-2는 구현상 필요조건일 뿐이다.

> **넣지 않은 검사 — "배수구 ↔ 밸브 동시 감시"**
> 최후 생존자 페이즈에서 밸브는 얼어붙은 상태다. `T = 14 − (개방 밸브 수 × 3)`은 진입 시점 값으로 고정되고, 도망자가 밸브를 더 여는 것은 손해다(8초를 써서 T를 3초 줄인다). 페이즈 중 밸브 회전음은 발생하지 않으므로 동시 감시할 대상이 없다. **§10.2-1의 조건②를 여기 그대로 적용하면 안 된다.**

## 2. 산출된 좌표

수면 영역을 구역의 인셋으로 두고 0.5m 격자로 전수 탐색했다.

| 구역 | 구역 크기 | **수면 영역** | 덱 폭 | 최대 인셋 |
|---|---|---|---|---|
| 메인 풀 홀 | 20×12m | **(21,17)~(35,25)** = 14×8m | 서3 동3 남2 북2 | 4.00m |
| 유아풀 존 | 12×9m | **(3.5,6.5)~(12.5,12.5)** = 9×6m | 사방 1.5m | 3.00m |

**채택 좌표**

| 배수구 | 좌표 | 육상 거리 | 밸브 거리 | 수심 |
|---|---|---|---|---|
| **배수구 1** (메인 풀) | **(31, 21)** | **4.00m** | B까지 3.16m | 3.5m |
| **배수구 2** (유아풀) | **(8, 9.5)** | **3.00m** | E까지 3.04m | **3.5m 국소 침강부** |

### 반드시 문서에 남길 사실

**유아풀의 육상 거리 3.00m는 기하학적 상한이다.** 수면 폭이 6m이므로 어느 점을 잡아도 3.0m를 넘을 수 없고, y = 9.5(수면 중앙선)에서만 달성된다. 합격 후보가 4개뿐인 이유가 이것이다.

> 수면을 넓히지 않는 한 **여유가 0이다.** 그레이박스에서 유아풀 수면을 조금이라도 줄이면 D-1이 즉시 깨진다. 메인 풀은 여유 1.0m(4.00 vs 3.00)가 있어 상대적으로 안전하다.

# ── 배수구 (§6.5-2 / §6.5-3) ────────────────────────────────────────

MIN_VALVE_D = 3.0    # D-2 배수구 ↔ 같은 구역 밸브 (상호작용 프롬프트 분리)

### 4-2. 함수 추가 (`co_watch_spots` 다음)

```python
def land_distance(p, water):
    """배수구에서 물 밖(육상)까지의 최단 거리 — 수면 사각형 경계까지의 거리"""
    x0, y0, x1, y1 = water
    return min(p[0] - x0, x1 - p[0], p[1] - y0, y1 - p[1])


def check_drains():
    """§6.5-3 수평 거리 제약 판정. 밸브 검사와 독립이다."""
    print(f"\n{'배수구':20} {'육상거리':>8} {'밸브거리':>8}  판정")
    print("-" * 54)
    bad = 0
    for name, (room, p, valve) in DRAINS.items():
        w = WATER[room]
        ld = land_distance(p, w)
        vd = math.dist(p, VALVES[valve])
        ok = ld >= MIN_LAND and vd >= MIN_VALVE_D
        if not ok:
            bad += 1
        cap = min(w[2] - w[0], w[3] - w[1]) / 2      # 이 수면에서 가능한 최대 육상거리
        note = "  ← 상한(여유 0)" if abs(ld - cap) < 1e-6 else ""
        print(f"{name:20} {ld:8.2f} {vd:8.2f}  {'OK' if ok else 'FAIL'}{note}")
    print(f"\n배수구 불합격 {bad}개 / 총 {len(DRAINS)}개")
    if bad:
        print("→ 조정: ①배수구 좌표 ②수면 영역 확대 (§6.5-3, §10.1)")
    return bad
```
