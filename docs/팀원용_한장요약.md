# 마르코! 팀원용 한 장 요약

> **읽기용 요약이다. 정본이 아니다.** 게임 규칙 · 수치의 정본은 `마르코_상세기획서.md`(v0.6)이고, 수치는 **부록 A**가 이긴다. 이 요약과 다르면 기획서가 맞다. 이 요약에 없는 것은 기획서에서 찾고, 기획서에도 없으면 `[GAP]` 이슈를 연다.
> 기준: 기획서 v0.6 + 2026-10-09 정리. 개발 규칙은 `작성규칙.md`.

---

## 1. 한 줄

**말해야 앞이 보이는데, 말하면 술래가 듣는다.**

완전한 암전에서 시작한다. 소리를 내면 **파문(SoundPulse)** 이 생겨 주변 지형이 잠깐 보이지만, 그 소리는 술래에게 위치를 알려 준다. 조용히 움직이면 안전하지만 아무것도 볼 수 없다.

```
완전한 암전 → 소리 발생 → SoundPulse → 제한적인 시야 확보 → 위치 노출 → 추적/회피
```

## 2. 게임 정보

| 항목 | 내용 |
|---|---|
| 장르 | 비대칭 음성 술래 호러 파티 (PC · Steam · Windows) |
| 인원 | **3~6인** (술래 1 + 도망자 2~5), 권장 5인. 시점 1인칭 |

## 3. 역할 3가지

| | 술래 | 도망자 | 메아리 |
|---|---|---|---|
| 인원 | 1 | 2~5 | 태그로 탈락한 도망자 |
| 목표 | 도망자를 잡거나 시간 종료까지 막는다 | 밸브를 열고 탈출한다 | 노크로 술래를 유인한다 |
| 이동 | 추격 5.0×(1.04~1.08) m/s (인원별, 5인 5.30) · 잠행 3.5 m/s | 걷기 5.0 · 질주 7.5 m/s (스태미나 5초) | 6.0 m/s, 벽 통과, 비행 |
| 듣기 | 반경 ×1.2 · 지속 ×1.5, 대화 · 고함은 방향 표시 | ×1.0 | 맵 전체 파문을 거리 · 차폐 무시하고 본다 (최근 8개, 잔류 3초) |
| 능력 | **태그**(좌클릭) · **외침**(R) | 찰칵이 · 붕대 · 동료 치료 · 잠수 | **노크**(G) 라운드당 5회 |

- **태그**: 좌클릭 1회 = 요청 1회. 판정 반경 1.2m, 전방 ±45°, 벽이 사이에 있으면 불성립. 쿨다운 적중 2.5초 / 헛스윙 1.5초. 서버가 다시 검증한다.
- **목숨**: 도망자는 2.0으로 시작한다. 첫 태그 → 1.0(**상처**, 6초마다 신음 파문 9m). 목숨이 2.0 미만일 때 태그되면 즉시 **메아리**. 붕대(G, 6초, +0.5) · 동료 치료(E 홀드 9초, 즉시 2.0)로 회복한다.
- **외침**: 선딜 1초 정지(움직이면 취소) → 쿨다운 45초. 22m 안 도망자가 자동으로 비명(9m)을 지른다. 선딜 1초 안에 숨 참기(Left Ctrl 탭, 게이지 4.5초)로 막을 수 있다. **술래는 비명을 10.8m까지만 듣는다** — 10.8~22m 도망자는 들켰다고 믿지만 술래는 모른다.
- **노크**: 메아리의 현재 위치에서 요청 1.5초 뒤 발생, 쿨다운 25초, 전환 후 20초 잠금. 술래는 대화 · 비명 · 노크 · 신음을 구분하지 못한다(의도).
- **숨 게이지 14초**: 잠수 -1/초, 비명 억제 -4.5. 마지막 소모 2초 뒤 수면 +2/초 · 물 밖 +4/초. 잠수 중 0이 되면 질식(이동 -20% 3초 + 고함급 파문).
- **정지 감지**: 20초간 누적 이동 3m 미만이면 호흡음 3m, 15초마다 +2m(최대 9m), 5m 이상 이동하면 초기화. 도망자 · 술래 적용, 메아리 제외.

## 4. 소리 · 청취

**청취 반경 = 발생 반경 × 재질 배율 × 역할 청취 배율 × 0.5^(통과한 벽 수)**

| 소리 | 발생 반경 / 지속 | 발생 조건 | 표현 |
|---|---|---|---|
| 속삭임 | 4m / 0.6초 | 마이크 -50~-30 dBFS | 링 |
| 대화 | 9m / 1.2초 | -30~-15 dBFS | 링 |
| 고함 | 22m / 2.5초 | -15 dBFS 이상 | 링 |
| 걷기 | 2m / 0.4초 (2m 이동마다) | 이동 | **소리만** |
| 질주 · 헤엄 | 6m / 0.8초 (6m 이동마다) | 이동 | **소리만** |
| 밸브 | 12m / 회전 시간 | 밸브 작업 중 | 링 |
| 비명 · 노크 | 9m / 1.0 · 1.2초 | 외침 억제 실패 · 메아리 | 링 |
| 호흡음 | 3m→9m / 0.6초 | 정지 감지 | 소리만 |

- 재질 배율(발생 반경에만): 금속 ×1.5 · 타일 ×1.3 · 콘크리트 ×1.0 · 카펫/매트 ×0.7. 물속은 파문 없음.
- 벽 한 장 통과마다 ×0.5, 수면 ×0.5, 층간 바닥 ×0.25. 차폐는 0.25초마다 다시 판정한다.
- **링 표시**는 파문이 지형을 잠깐 비추고, **소리만** 표시는 링 없이 소리로만 전달한다(이동 소리). 잔상은 링 표시 파문의 지형 모서리를 12초(15%→0%) 남긴다.
- 음성은 VAD(오픈 마이크)가 기본이고 설정에서 PTT(V)로 바꾼다. 강제 뮤트 Left Alt(홀드).

## 5. 승리 조건

**밸브 5개가 배치되어 있고, 매 라운드 서버가 3개를 활성화한다.**
- 활성 = **B(경영풀 수중) · E(교습풀 수중) 고정** + A(기계실) · C(물탱크실 2층) · D(약품 저장실) 중 1개.
- **활성 3개를 동시에 개방**하면 출구 게이트가 열린다(탈출이 가능해질 뿐 승리는 아니다. 한 번 열리면 유지).
- 밸브 1개의 총 점유 시간은 **8.0초로 균등**(1인 기준). 2인이 같이 하면 ×1.6, 3인 ×1.9가 상한. 중단하면 3초 유예 뒤 초당 -0.10으로 줄어든다.
- 개방된 밸브는 **180초 뒤 30초에 걸쳐 닫힌다(역류)**. 다시 열어야 한다.
- 밸브 · 배수구는 도망자만 조작한다. 상호작용 범위 1.5m(E 홀드).

**라운드 종료와 판정**
- 라운드는 **도망자 전원이 탈출 또는 포획**되거나 시간이 끝나야 끝난다. 태그 수로는 끝나지 않는다.
- 도망자 승리: **탈출 인원 ≥ ⌈도망자 ÷ 2⌉** 또는 **최후 생존자가 탈출**. 그 밖은 술래 승리.
- 출구는 정문 · 직원 출입구 2곳(판정 반경 2m). 한 프레임에 탈출과 태그가 겹치면 탈출이 먼저다.

| 도망자 | 총원 | 탈출 요구 | 술래 이속 보정 | 제한시간 |
|---|---|---|---|---|
| 2 | 3 | 1 | +5% | 8분 |
| 3 | 4 | 2 | +4% | 10분 |
| 4 | 5 (권장) | 2 | +6% | 10분 |
| 5 | 6 | 3 | +8% | 12분 |

**최후 생존자 페이즈**: 생존 도망자가 1명이 되면(InGame에서만 판정) 90초 제한이 걸리고, 활성 배수구 한 곳에서 고함급 파문이 울린다. 배수구는 2곳 중 무작위 1곳(경영풀 깊은 쪽 · 교습풀 침강부, 수심 3.5m)이고 작업 시간은 **T = 11 − 3×(동시 개방 밸브 수)**초(하한 1초)다. 마지막 생존자가 탈출하면 도망자 승리. 게이트가 이미 열려 있으면 활성화하지 않는다.

**종반 압박**: 잔여 2분 저역 드론(연출) · 잔여 1분 술래 이속 +5% · 잔여 30초 양쪽 출구에서 고함급 파문 5초 주기.

## 6. 라운드 흐름

```
Boot → MainMenu → Lobby → RoleAssign → InGame → (LastSurvivor) → RoundEnd → Lobby / RoleAssign(리매치)
```

- **RoleAssign**: 3초 연출, 역할 배정, 맵 로드 후 **브리핑 30초**(평면도 · 활성 밸브 공개, 전원 이동 잠금).
- **InGame**: 타이머 시작, 술래는 3초간 격리 지점에서 이동 불가.
- **RoundEnd**: 어워드 3종 — 최다 비명상(`Scream` 횟수) · 무성 생존상(이동량 대비 소음량) · 최고의 거짓말상(노크 유인 성공).
- 로비로 돌아오면 전원 처음 입장한 상태로 돌아온다(메아리 해제).

## 8. 구현 원칙

- **서버가 결정한다.** 클라이언트는 입력 의도만 요청하고, 서버가 상태 · 거리 · 대상을 검증해 확정한다. 거부된 요청은 조용히 무시한다. 청취자가 알면 안 되는 정보(차폐된 좌표, 목숨)는 서버가 보내지 않는다. 이동만 클라이언트 권위다. (기획서 14.2)
- **어셈블리 3개**: `Core`(게임 로직 · 수치 · 차폐 판정) · `Net`(FishNet 격리 · 이벤트 직렬화) · `Presentation`(UI · 파문 렌더링 · 사운드). `Core`는 FishNet을 직접 참조하지 않는다. (15.2 · 15.3)
- **수치는 코드에 만들어 넣지 않는다.** 필요한 값이 부록 A에 없으면 `[GAP]` 이슈를 연다.
- 개발 단계는 기획서 20절의 P0 → P1 → P2 → Alpha 순이고, **다음 단계의 시스템을 미리 구현하지 않는다.**
