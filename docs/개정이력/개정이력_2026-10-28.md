### 술래 드론 [10-28]

**술래 전용 저역 드론은 "도망자 정보가 없다"는 신호다.** 켜지는 조건이 없던 "술래 전용 저역 드론 앰비언스"에 규칙을 확정한다. 표현(오디오) 규칙만 추가하며 게임플레이 수치는 바꾸지 않는다. 숫자 정본은 부록 A [술래 드론 — 10-28].

| 항목 | 값 |
|---|---|
| 듣는 사람 | **술래 본인만**(로컬 전용, 네트워크 없음 — 14.2) |
| 켜지는 조건 | 술래에게 **남이 낸 파문 · 소리 이벤트가 20초 동안 하나도 도착하지 않음** |
| 1단계 | 침묵 20초 → 30초: 10초에 걸쳐 최대 볼륨의 **60%**까지 페이드인 |
| 2단계 | 침묵 30초 → 60초: 선형으로 **100%**까지. 60초 이후 100% 유지 |
| 꺼지는 조건 | 남의 이벤트가 **하나라도** 도착하면 **0.2초** 페이드아웃, 침묵 타이머 0으로 |
| 타이머 시작 | 술래 격리 해제 순간부터 센다(10.5 · 15.4) |
| 쓰지 않는 구간 | 술래 격리 중 · **잔여 2분 이후**(종반 드론이 10초 페이드인하는 동안 크로스페이드로 교대 — 6.2-1 · 연출 10) · 결과 화면 |

**"남의 이벤트"의 정의.**
- 서버가 술래에게 보낸 **모든 청취 결과**다 — `PerceivedPulse`, 소리만 타입 재생, 타인의 바닥 링(5.5-3)이 따라오는 파문 등 표현 방식과 상관없이 도착한 것 전부. 종류를 가리지 않는다.
- **발소리 · 신음 · 비명 · 노크 · 밸브 · 역류 물소리 · 게이트 개방음 · 태그 파문 · 종반 출구 파문 전부 똑같이 드론을 끈다.** 노크에만 다르게 반응하면 술래가 드론으로 노크와 비명을 구별하게 되어 구분 불가 그룹(5.1 비명 · 노크 · 신음)이 깨진다.
- 술래 **본인이 낸 소리**(본인 발소리 · 본인 `Walk` 바닥 링 · 말 · 외침)는 타이머를 **리셋하지 않는다.** 드론은 "도망자 정보가 없다"는 신호라, 본인 소리로 끌 수 있으면 의미가 없다. 외침이 도망자 비명을 끌어내면 그 비명이 드론을 끈다.
