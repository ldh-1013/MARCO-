# 술래 외침 / 자동비명 구현

- 네트워크 플레이어의 PlayerMovement partial에 연결되어 프리팹 재설정 없이 동작한다.
- 술래 R: 서버에서 1초 준비, 시작 위치로부터 0.15m 초과 이동 시 취소. 완료부터 45초 쿨다운.
- 완료 시 직선거리 22m 이내 살아있는 도망자는 자동비명. 잠수 또는 억제 성공자는 제외.
- 준비 중 Left Ctrl: 서버가 대상 여부를 확인하고 공유 숨 게이지 4.5를 한 번 차감한다.
- 비명 반경 9m / 1초, 외침 반경 22m / 2.5초. 기존 서버 청취 경로로 벽·물·술래 청취 배율을 적용한다.
- 본인 피드백과 대상별 RPC만 전송한다. 원거리 술래에게 비명 발생 메시지를 방송하지 않는다.
- 서버 ScreamCount는 실제 발생만 집계하고 라운드 이동 자원 초기화와 함께 초기화한다. 결과 어워드 UI 연결은 별도다.
- HUD에 외침 준비/쿨다운과 숨 참기 안내, 본인 비명에 백색 화면 가장자리 효과를 표시한다.
- 생존자 자동비명은 Resources/MarcoSound/Scream.mp3에 연결한 girl-scream(자동비명).mp3를 사용한다. 약 1.37초 녹음을 끝까지 재생하며 파문 지속은 1초로 유지한다. 헌터 Shout 전용 녹음이 없으면 Hurt를 임시 대체음으로 사용한다.

검증: diff 공백 검사 완료. Unity 6000.5.4f1 배치 실행은 프로젝트 경로 진입 직후 종료 코드 1로 끝나 컴파일 및 호스트/클라이언트 플레이 검증은 완료하지 못했다.
플레이 확인 항목: 이동 취소 후 즉시 재사용, 45초 재사용 제한, 10m/15m/23m 대상, 벽 뒤 대상, Ctrl 중복 차감 방지, 숨 부족, 잠수, 라운드 재시작, 원격 클라이언트 입력.
