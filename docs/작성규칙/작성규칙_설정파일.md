- 신규 · 갱신: 
- EditMode 전체: __ / __ 통과 (문서 · 아트 PR은 "해당 없음")

## 리뷰 체크 (작성자 먼저 확인)

### A-7. UnityYAMLMerge 등록 (각자 PC, 권장)

`<Unity 설치 경로>`는 Unity Hub로 설치했다면 보통 `C:/Program Files/Unity/Hub/Editor/6000.5.4f1/Editor/Data/Tools/UnityYAMLMerge.exe`다 — 각자 확인.

```ini
# git config --global --edit 에 추가
[merge]
    tool = unityyamlmerge
[mergetool "unityyamlmerge"]
    trustExitCode = false
    cmd = '<Unity 설치 경로>/UnityYAMLMerge.exe' merge -p "$BASE" "$REMOTE" "$LOCAL" "$MERGED"
```

### A-8. `CLAUDE.md` 초안 (레포 루트, 200줄 이하)

```markdown
# 마르코! — Claude Code 프로젝트 지침

## 정본 (먼저 읽는다)
- 게임 규칙 · 수치: docs/마르코_상세기획서.md (수치는 부록 A가 이긴다)
- 좌표 · 도면: docs/맵설계.md / 연출: docs/연출.md
- 문서 읽는 순서: docs/README.md / 팀 규칙: docs/작성규칙.md
- docs/archive/ 와 프로토타입 기록은 현행 규칙이 아니다

## 절대 하지 않는다
- 기획서에 없는 수치 · 규칙을 코드에 넣지 않는다 → 멈추고 [GAP] 이슈를 제안한다
- main에 커밋 · 푸시하지 않는다. 강제 푸시하지 않는다
- 씬(.unity) · 프리팹(.prefab) · .meta 파일을 텍스트로 직접 고치지 않는다
- docs/ 문서를 고치지 않는다 — 기획 담당자의 세션만 고친다. 그 밖의 세션은 [GAP] 이슈를 제안한다
- Assets/FishNet/ 을 고치지 않는다
- 이슈 하나 · 브랜치 하나 범위를 벗어난 파일을 고치지 않는다

## 아키텍처
- Assets/_Project/ — Core / Net / Presentation / Editor / Tests (asmdef로 분리)
- Core: UnityEngine.Time · Input · Physics · MonoBehaviour · FishNet 금지 (EditMode 테스트 대상)
- Net → Core + FishNet / Presentation → Core. Net ↔ Presentation 직접 참조 금지
- 서버 권위: 클라이언트는 의도만 보낸다. 신원 · 역할 · 위치 · 시간은 서버가 읽는다
- 레지스트리(LocalPlayerRegistry 등) 값을 필드에 저장하지 않는다

## 코드
- 기획 수치는 설정 클래스 한 곳 + XML 주석에 기획서 § 인용. 유도 가능한 값은 계산
- 새 public 메서드는 프로덕션 호출부와 라운드 초기화 경로를 함께 만든다
- enum · 인터페이스 변경 시 읽는 곳을 전수 검색해 같은 커밋에서 고친다
- 명명: PascalCase 타입 · 메서드 · 상수 / _camelCase private 필드 / I 인터페이스
- 테스트: Assets/_Project/Tests/EditMode/, 이름 대상_조건_기대결과, 경계값 포함

## 커밋 · PR
- 커밋 · PR 제목: 타입(영역): 한국어 요약 (§절)  — (§절)은 기획서 근거가 있는 변경에 필수 / 타입 feat fix test refactor docs art chore / 영역 core sound net ui map art docs config
- 코드와 테스트는 같은 커밋. 테스트 실패 상태로 푸시하지 않는다
- AI가 참여한 커밋 끝에 `Co-Authored-By: <사용 중인 모델 이름> <noreply@anthropic.com>` 트레일러를 남기고 PR 템플릿 "AI 사용" 칸에도 적는다(자동으로 붙지 않으면 직접 쓴다 — 자동 설정 이름은 확인 필요). main의 Squash 커밋에는 남지 않을 수 있다 — 추적은 PR 번호 `(#N)`로 한다
- PR 본문은 .github/pull_request_template.md 를 채운다

## 보고
- 변경 전/후, 계산 검증(수치), 테스트 결과, 범위 밖으로 남긴 것
- 문제가 남으면 완료라고 보고하지 않는다
- 지시와 기획서가 충돌하면 실행하지 말고 먼저 알린다
```
