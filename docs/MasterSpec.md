# 프로토타입 명세

로비는 암전하지 않는다. Hunter/Survivor의 기본 월드 시야는 완전 암전이며, 음량이 커질수록 중앙 원형 시야 반경이 연속적으로 증가한다. HUD는 암전 위에 표시한다. 개발 F8은 전체 시야를 연다.

Create room은 TCP 리스너를 시작하고 호스트를 방에 입장시킨다. 생성 후 IP:port와 해당 주소를 인코딩한 MARCO 코드를 각각 복사할 수 있다. Join은 둘 중 하나만 입력하며 연결/서버 승인 이후 입장을 확정한다. 서버가 참가자 수를 전달하고 연결 종료를 반영한다.

범위: LAN 또는 연결 가능한 VPN IP의 로비 접속. 인터넷 짧은 코드 매칭/Relay/NAT 통과와 플레이어 게임플레이 동기화는 후속 작업이다. 코드는 주소 인코딩이며 비밀번호가 아니다.
# 로비·Hunter 애니메이션 보완 (2026-10-07)
- 로비 최초 메뉴: 닉네임, Create room, Join. Join 선택 이후에만 IP/코드 입력과 접속/취소 표시.
- 방 생성 후 기존 참가자 목록과 초대 IP 복사 UI 유지.
- 플레이어 Hunter는 좌클릭 및 쿨다운 조건을 통과할 때만 단발 공격 모션. 조준만으로 공격하지 않음.
- Survivor 씬 Hunter 허수아비는 테스트용 주기 공격 유지. 병합 때 제거.
- Chan DAMAGED00/01은 후보 클립이며 아직 실제 피격에 연결하지 않음.

## Hunter 대기·이동·단발 공격
- 정지 시 Idle1, 실제 수평 이동 시 Walk1. 조준만으로 공격 모션을 재생하지 않는다.
- Punch1 원본 전체를 재생하지 않고 첫 0.8초 구간만 기본 0.45초에 재생한다. 공격 쿨다운과 모션 지속 시간은 독립적이다.
- 공격 모션 종료 즉시 현재 이동 상태(Idle/Walk)로 복귀한다. 공격 중 이동 입력/CharacterController 이동 자체는 막지 않는다.
- Survivor 씬 Hunter 허수아비의 3초 주기 태그는 유지하되 매번 같은 단발 모션만 재생한다.
