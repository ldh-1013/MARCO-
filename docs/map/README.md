## 3D 뷰어 사용법

- 파일을 **내려받아 브라우저로 연다.** GitHub 화면에서는 소스만 보이므로 반드시 내려받아 연다.
- 보기 방식은 두 가지다: 위에서 둘러보기 / 걸어서 보기.
- 걷기 조작: WASD 이동, Shift 달리기, 드래그로 시점 이동, 계단 앞에서 E, Esc로 둘러보기 복귀.
- **인터넷 연결이 필요하다.** 3D 라이브러리와 글꼴을 외부에서 불러온다.
- 풀 수심은 맵설계.md 5절 수심 분포를 따른다: 경영풀 1.8m, 경영풀 동쪽 끝 6m 구간(깊은 쪽) 3.5m, 교습풀 1.2m, 교습풀 배수구 둘레 침강부(반지름 1.2m) 3.5m. 깊은 쪽 경계는 3D에서 단차로 단순화했다.

## 주의

- 도면의 색은 **검토용**이며 게임 팔레트(기획서 §16.2)와 무관하다. 3D 뷰어의 "게임 화면처럼 보기"만 게임 스타일에 가깝게 그렸다.
- 락커 · 레인 로프 · 탱크 등 3D 물체의 모양은 맵설계의 기호를 방 종류에 맞게 해석한 **임시 표현**이다. 실제 모델은 아트 작업에서 정한다.

## 갱신 규칙

맵 배치(`docs/맵설계.md`의 ASCII 도면)가 바뀌면 이 자료는 모두 다시 만들어야 한다. 도면만 고치고 이 폴더를 그대로 두면 둘이 어긋난다.
