# 설치형 소리통 — 구현 메모

작성: 2026-11-04. 사용자 요청: 기존 투척형 프로토타입에 이어 설치형을 구현한다.

## 기획서에서 정해진 내용

`마르코_상세기획서.md` §7: **목소리 3초 녹음 → 설치 → 원격 재생**, 재생 시 **대화 등급 파문**, 맵당 **2곳**. 녹음은 **세션 메모리에만 존재하고 판 종료 시 삭제**한다. 소리통과 고무오리는 독립 아이템이며, 녹음을 고무오리로 전달하는 연결 기능은 없다.

## 이번 프로토타입에서 정한 내용 — 기획 확정값이 아님

아래 조작·배치·보유·소모 규칙은 기획서에 없으므로 구현 시작값으로 구분한다. 정식 편입 시 기획서에 반영할 `[GAP]` 항목이다. 코드 수치는 `SoundCanConfig.cs`에 모았다.

녹음 중 목소리는 기존 근접 음성으로도 전달된다. 녹음을 이유로 살아 있는 플레이어에게 말을 숨기는 기능은 추가하지 않았다. 녹음은 이동하며 할 수 있다. 파문 표시는 현재 프로젝트의 바닥 링 렌더러를 사용하며, 재생 음성은 장치 위치에서 들린다. 장치의 모델은 임시 박스형 녹음기다.

## 권위와 데이터 수명

- **서버 권위:** 획득·보유 상태·녹음 세션 토큰·150개 프레임 순서·3초 완료 시간·설치 위치·원격 재생·청취자별 전달·소모.
- 클라이언트는 자기 마이크의 20ms 샘플을 기존 `VoiceCodec`으로 320바이트 μ-law 프레임으로 전송한다. 서버 녹음 한 개는 16kHz 모노, 150프레임, 총 48,000바이트다. 재생 때 3초 PCM 오디오로 복원한다.
- 토큰·순서·크기가 잘못되거나 중복된 프레임, 완료·취소한 녹음에 대한 프레임을 거부한다. 150프레임을 즉시 전송해도 서버의 3초가 지나야 설치할 수 있다.
- 녹음 상태·진행도·토큰은 소유자만 받는다. 설치된 장치의 위치는 월드 오브젝트 표시를 위해 동기화한다.
- 녹음 데이터는 재생 전 다른 클라이언트에게 배포하지 않는다. 재생 중 청취 판정을 통과한 플레이어에게만 해당 시점의 프레임을 전달한다. 벽 뒤에는 정확한 위치 대신 기존 8방위 대리 재생 위치·감쇠·저역 필터를 적용하고 링은 표시하지 않는다.
- 오디오 파일을 만들거나 디스크에 저장하지 않는다. 취소·소모·탈락·판 종료 시 서버의 바이트 배열을 지우고, 클라이언트 재생용 AudioClip을 폐기한다.
- 기존 씬·플레이어 프리팹 변경 없이 라운드와 플레이어 코드에서 동작한다.

설치 동작은 `CharacterMotion.SoundCan.cs`의 절차적 포즈로 구현했다. 기존 무릎 굽힘 위에 상체 숙이기, 양팔의 2관절 도달, 손목·손가락의 작은 반복 동작을 얹는다. 임시 장치를 양손 사이에 표시한 뒤 놓는 시점에 숨긴다. `FirstPersonBody`가 같은 몸과 손을 보여 주므로 본인과 타인에게 같은 모션이 적용된다. 설치 상태·목표점·진행도는 서버가 동기화하며, 애니메이션만으로 설치를 완료하지 않는다. 설치 시간 2초와 카메라의 최소 하향 목표 55도는 이번 표현 요청에 맞춘 프로토타입 값이다.

## 검증

Unity 6000.5.4f1의 별도 프로젝트 복사본에서 `Marco.Network.Editor.SoundCanChecks.Run`을 실행한다. 실제 FishNet LAN 호스트에서 합성 마이크 프레임을 기존 코덱과 캡처 RPC에 공급해 녹음·설치·원격 재생을 검사한다. 실제 마이크 하드웨어와 두 명의 청취 체감은 별도의 실플레이 확인 대상이다.

2026-11-04: 컴파일 및 실행 검증 PASS, 종료 코드 0 (`Logs/SoundCanChecks.log`). 소유자 상태 전달, 150프레임 캡처 RPC, 녹음/재생 파형 일치, 범위 밖 전달 중단, 잘못된 토큰·프레임·인덱스·중복 요청 거부, 취소/재녹음, 바닥 없는 설치 거부, 원격 재생, 1회 소모, 탈락/초기화 시 데이터 정리를 확인했다. 검증 복사본의 Unity Search 초기화 예외는 별개로 기록됐으며 소리통 검증은 정상 완료됐다. 원본 씬과 공용 프리팹은 수정하지 않았다.

같은 날 설치 모션 추가 검증: D3D11 배치 에디터에서 컴파일 및 확장 실행 테스트 PASS, 종료 코드 0 (`Logs/SoundCanPlacementChecks.log`). 2초 설치 지연, 설치 중 미생성·재생 차단, 웅크리기/이동 잠금, 손 도달·손가락 움직임, 취소 시 녹음 보존, 서 있던 상태와 기존 웅크린 상태의 복구를 확인했다. `Logs/SoundCanPlacementPreview/`의 1인칭 렌더 PNG로 양손과 장치가 화면 안에 보이는 것도 확인했다. 렌더 검수는 별도 테스트 바닥과 개발용 전체 시야를 사용했다. 원본 맵 색상이나 씬 조명은 바꾸지 않았다.

2026-11-05 배치 검증: 사용자가 지정한 계단식 좌석 단(o70) 맨 아래 단에 녹음기 1개만 배치하도록 변경했다. Unity 6000.5.4f1 별도 복사본에서 표면 높이 3.9m, 모델 바닥 3.91m, 앞에서 픽업까지 약 1.031m 거리와 가려지지 않는 획득 경로를 확인했다. 겹침 없음 및 컴파일 통과, 종료 코드 0 (`Logs/ItemPlacementFinal.log`). 검수 렌더는 `Logs/ItemPlacementFinal/o70.png`에 있다.

2026-11-05 재생 증폭 검증: 실제 호스트에서 합성 녹음을 캡처 RPC로 저장하고 원격 재생한 결과, 낮은 입력의 RMS가 2배 이상 증가하고 원래 파형과의 정규화 상관계수가 0.98을 초과하며 모든 출력 샘플이 ±1 안에 있음을 확인했다. 설치·취소·녹음·재생·거리 제한·정리 검사 PASS, 종료 코드 0 (`Logs/SoundCanChecks-ItemFix.log`). 실제 마이크 하드웨어의 청취 음량은 별도 실플레이 확인 대상이다.
