# 현재 작업 계획

## 공격 단발 구간·걷기 복구
1. 원본 공격 클립 재생 길이와 공격 지속 시간/쿨다운을 분리한다.
2. 대기·걷기·공격 3개 클립을 독립 제어하고 실제 이동량으로 걷기 전환한다.
3. 클립 한 번을 짧은 공격 시간에 맞춰 재생 후 즉시 이동 상태로 복귀. 시간 경계 테스트 및 C# 컴파일 확인, 실제 화면 미검증은 구분한다.

## setting 표기·헌터 반복 모션 재점검
1. 설정 메뉴/팝업 제목을 setting으로 통일한다.
2. 플레이어 공격 입력과 허수아비 자동 공격을 구분하고, 대기는 정지 포즈로 고정한다.
3. 공격 클립을 입력 시에만 진행시키고 복귀를 클립 시간/렌더링 컬링과 무관한 타이머로 제어한다. 검증 결과와 실행 미검증 범위를 기록한다.

## 닉네임 배치·설정 진입점
닉네임 제목과 입력을 중앙 상단에 정렬하고 Join 아래 설정 메뉴 및 중앙 준비용 팝업을 추가한다. 설정 기능은 별도 확정 전 구현하지 않는다.

## Join 중앙 팝업
기본 하단 안내 문구를 숨기고 실제 오류/접속 상태만 좌측 하단에 표시한다. Join 입력은 중앙 팝업으로 이동하고 팝업이 열린 동안 뒤 메뉴 입력을 막는다.

## 로비 메뉴 배경 재수정
버튼 스킨 상속을 없애 배경을 제거하고, 레터박스 여백을 보정해 메뉴 시작을 실제 화면 왼쪽 8px에 고정한다. 닉네임 중앙 배치는 유지한다.

## 로비 텍스트 메뉴 배치
1. 최초 화면의 외곽 박스와 메뉴 버튼 배경 제거.
2. 큰 텍스트 메뉴는 좌측, 닉네임은 중앙 배치. 기준 해상도에 맞춰 전체 UI 축소하여 화면 내 유지.
3. 방 내부 기능 유지 및 검증 범위 기록.

## 로비 간소화·공격 모션 제어
1. 첫 화면에는 닉네임, Create room, Join만 표시하고 Join 선택 시 주소 입력을 펼친다.
2. Demon 데모 컨트롤러의 자동 전이를 제거하고 대기/단발 공격 클립만 직접 재생한다. 테스트 허수아비의 주기 공격은 유지한다.
3. Chan 피격 클립 존재 여부를 확인하고 실제 재생 검증 여부를 구분해 기록한다.

## 실제 게임 씬 병합 시 필수 정리
- 사용자에게 테스트 허수아비 제거가 필요하다고 안내한다.
- Survivor 씬의 Hunter Training Dummy와 그 Demon 모델, 자동 공격 컴포넌트를 제거한다.
- Hunter 씬의 Tag Target - Survivor와 Chan Survivor Target 테스트 모델을 제거한다.
- 실제 플레이어/헌터의 모델 및 태그·체력·고스트 기능은 유지하고 실제 네트워크 캐릭터에 연결한다.
- 테스트 HUD, F6/F7/F9 치트, Show Debug State 등 개발 기능의 배포 포함 여부를 확인한다.

## Hunter 허수아비 수정
Survivor 씬 흰 큐브 대상의 생존자 설정을 제거하고 Demon 프리팹을 배치한다. 주기적 Hunter 스윙과 기존 생존자 체력을 연결한다. Hunter 조준 표시와 공격 애니메이션, 고스트 치트도 앞선 요청대로 적용한다. 실제 Unity 컴파일 결과를 기록한다.

## 에셋 컴파일 오류 확인
1. 실제 Unity 로그의 오류 파일과 누락 의존성을 확인한다.
2. Ghost 에셋의 UGUI 의존성을 프로젝트에 추가한다.
3. 실제 Unity 컴파일 또는 Unity의 생성된 컴파일 명령으로 전체 런타임 스크립트를 검증한다.

## 캐릭터 에셋·고스트
1. Chan/Demon/Ghost 원본 에셋을 확인하고 씬의 시각 모델로 배치한다.
2. Survivor 씬 플레이어에 체력과 고스트 전환을 연결한다. F6 두 번으로 태그 테스트, F7 초기화.
3. 고스트는 충돌 없는 이동으로 전환한다. 1인칭 자기 모델은 카메라에서 숨긴다.
4. 컴파일 및 프리팹 참조를 확인하고 실행 미검증을 기록한다.

## 시작 버튼·그레이박스·v0.5 태그
1. 방 내부에 시작 버튼(현재는 준비용)을 추가한다.
2. 두 역할 씬의 바닥/대상을 흰색 무광 재질로 통일한다.
3. 생존자 지정, 정상 2 → 상처 1 → 메아리 0 및 회복 중 1.5 판정을 구현한다.
4. 1.2m/수평 ±45도/가장 가까운 1명/쿨다운 판정과 스윙·적중 반응을 추가한다.
5. 상태 전이 실행 테스트, 컴파일, 씬 배선 확인 결과를 기록한다. 신음은 주기/반경 데이터와 디버그 신호로 검증한다.

## 로비 참가자 목록
1. 입장 전 닉네임 입력을 추가한다.
2. 서버가 닉네임과 고유 참가자 ID 목록을 전송한다.
3. 로비 중앙에 현재 참가자 목록을 표시하고 IP 복사는 하단에 배치한다. 입장 알림은 표시하지 않는다.
4. 스크립트 컴파일을 확인하고 실행 미검증 범위를 기록한다.

1. 역할 씬의 마이크 시야를 중앙 원형 개방으로 변경한다.
2. 무음/뮤트 시 완전 암전, F8 개발 시야와 Inspector 수치를 유지한다.
3. TCP 방 생성/접속, 주소와 코드 복사, 참가자 수, 나가기 UI를 구현한다.
4. 코드 변환 및 실제 TCP 연결 검증과 C# 컴파일 결과를 Status에 기록한다.
