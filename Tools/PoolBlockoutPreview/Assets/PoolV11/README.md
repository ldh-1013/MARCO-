# 심야 실내수영장 v1.1 — 문서 좌표 기준 블록아웃

## 열기

1. Project 창에서 `Assets > Scenes > IndoorPool_v1_1`을 더블클릭합니다.
2. Scene 창에서 `Buildings`를 선택하고 마우스를 Scene 위에 놓은 뒤 F를 누르면 전체가 보입니다.
3. Play를 누르면 좌측 상단에 맵 보기 패널이 표시됩니다.
   - `1F` / `2F` / `ALL`: 층 선택.
   - 벽 높이 슬라이더: 보기에서 벽 위쪽만 숨깁니다. 0은 전체 높이입니다. 실제 벽 크기와 Collider는 변하지 않습니다.
   - `Room labels`: 방 이름 표시.
   - `Valves / exits / item markers`: 밸브·출구·배수구·아이템 후보 표시.
   - 오른쪽 마우스 버튼을 누르고 움직이면 회전, 휠은 확대/축소입니다.
   - `Explore inside (fly)`: 로비 눈높이에서 맵 내부를 보는 자유 카메라입니다. 오른쪽 버튼을 누른 채 WASD 이동, Q/E 상하, Shift 가속입니다. 벽을 통과하며 충돌·수영을 구현한 플레이어가 아닙니다.
   - `Reset view`: 처음 시점으로 복귀.
4. Play에서 나오면 편집 상태로 돌아갑니다. 기존 `IndoorPool_Blockout`은 보존돼 있습니다.

## 기준과 좌표

`Design/MapDesign_v1_1.md`는 제공받은 `맵설계.md`의 사본이고 `Design/Layout_v1_1.json`은 §§5·7·9의 표를 구조화한 데이터입니다. 이 문서의 **새 맵 v1.1**을 구현했으며 문서 안의 과거 "현행" 맵과 구분합니다. 이전 아트 목록보다 이번 문서의 좌표·치수를 우선했습니다.

- 문서 `(x, y)` → Unity `(X=x, Z=y)`; 문서의 지점 높이 → Unity Y. 원점은 남서 모서리.
- 외곽 64×62m. 외벽 0.3m는 외곽선 바깥에 있습니다. 내벽은 중심선 기준 0.2m.
- 1층 17구역 + 2층 4구역 = 21구역. 설비 샤프트 PS1·PS2·PS3은 별도 보행 불가 공간입니다.
- 2층 바닥 Y=3.5. 슬래브 두께 0.5이므로 그 아래 유효 높이는 3.0m입니다.
- 로비·직원 통로·풀 홀의 합집합 사각형까지 반영했습니다. 이전 임시 맵의 중앙 통로는 새 설계의 구역으로 세지 않습니다.
- 문 25개와 외부 출구 문 2개를 별도로 구성했습니다. 문 폭·위치는 §7 표대로입니다. **개구부 높이는 문서에 별도 수치가 없어 2.5m 임시값을 사용했습니다.**
- 계단 S1·S2 폭 3m, S3 폭 2m. 세 계단 모두 수평 6m·높이 3.5m, 경사 약 30.256°입니다. 이전 아트 목록의 정확히 30° 대신 문서 발자국을 따릅니다.
- 경영풀 `(15,37)–(40,58)`: 25×21m, 일반 수심 1.8m, 동쪽 X34~40은 3.5m.
- 교습풀 `(3,41)–(11,53)`: X방향 8m·Z방향 12m, 일반 수심 1.2m. `(7,47)`에 실제로 뚫린 반지름 1.2m 원형 침강부가 있으며 바닥은 -3.5m입니다.
- 관람석 `(15,26)–(40,34)`: 풀과 3m 이격. 좌석은 6단, 2.4m까지 높아지며 ㄷ자 통로를 남겼습니다.
- 지붕은 `Environment/Roofs_Optional`에 있으며 내부 검토를 위해 기본 숨김 상태입니다. 지붕은 검토용으로, 계단 관통부 등 최종 건축 상세는 별도 조정 대상입니다.

## 추가한 오브젝트

- 밸브 A~E 5개: 문서의 좌표와 수중 높이까지 반영한 같은 핸들 Prefab 인스턴스.
- 출구 1 하역 셔터 / 출구 2 정문 양개문: 외벽에 실제 개구부를 만들고 판정 위치에 반지름 2m Trigger를 배치. 셔터는 열린 임시 형상입니다.
- 배수구 2개: 두 곳 모두 Y=-3.5. 배수구 커버 Prefab 재사용.
- 붕대 후보 b1~b9 9곳, 찰칵이 c1~c4 4곳.
- 문서 §9.3의 가구·장애물 82개 배치 항목(락커 열·기둥·출발대의 반복 항목을 전개한 수).
- 도망자 기준점 R의 4열×2행 후보 슬롯 8개. `SpawnPoints`에는 4인용으로 도망자 슬롯 3개와 술래 위치 1개를 `SpawnPoint_1`~`SpawnPoint_4`로 배치했습니다. 빈 Transform이며 생성 코드는 없습니다.
- 응급처치실 침대 2개는 §5의 랜드마크지만 §9.3에 정확한 배치 좌표가 없어 임시 위치의 비충돌 시각 모델로 구분했습니다.

## 조립과 FBX 교체

`Generated/Prefabs`에 벽·바닥·문틀·계단·풀·소품·밸브·배수구 모듈이 있습니다. 씬에는 Prefab 인스턴스를 배치했습니다. `PoolV11Part`의 ID·이름·규격·구역 필드로 원본 표와 대조할 수 있습니다. 락커는 소리·태그 차폐 대상으로, 다른 소품은 이동 장애물로 구분하는 메타데이터를 남겼습니다. 실제 차폐 시스템은 구현하지 않았습니다.

FBX를 받은 뒤:

1. Project에 FBX를 넣습니다.
2. Hierarchy에서 교체할 벽·바닥·소품 모듈을 선택합니다.
3. `Tools > Indoor Pool v1.1 > Replace Selected Module Visual`을 엽니다.
4. FBX/Prefab 칸에 모델을 넣고 `Replace Visual (keep collision)`을 누릅니다.
5. 원래 모듈 범위 안에 비율을 유지해 맞추고, 기존 시각 모델만 숨깁니다. 충돌은 유지합니다. Ctrl+Z로 되돌릴 수 있습니다.

단위 도형 모듈은 씬에서 축척을 적용하므로 실측 FBX를 자식으로 바로 넣으면 이중 확대될 수 있습니다. 위 도구는 그 축척을 보정합니다. 모델 비율이 다르면 남는 공간이 생기므로 최종 치수와 충돌을 확인하세요. 계단·풀·문은 전용 조립 구조라 수동으로 맞춰야 합니다.

## Hierarchy

- Environment: 풀, 카메라, 검토용 지붕.
- Buildings: 층별 21구역, 벽, 바닥, 문, 계단, PS 설비 공간.
- Obstacles: 층별 소품·좌석·추가 랜드마크.
- GamePoints: 밸브·출구·배수구·아이템 후보·기준 스폰.
- SpawnPoints: 4인 시작 위치.
- Collision: 수심별 물 볼륨. 개별 모듈의 Collider는 해당 Prefab의 `Collision` 하위에서 관리합니다.
- Labels: 층별 검토용 이름.

## 검증 범위

`PoolV11Reports/Validation.txt`와 `ReloadValidation.txt`에서 좌표·개수·수심·문/시작 위치·방 연결·계단 여유 공간 검사 결과를 확인할 수 있습니다. 별도 복사본에서 Unity를 실행해 저장·재열기를 검증했습니다.

문서의 이동 시간, 루프 길이, 엄폐 거리, 음향 차폐, 밸브 동시 청취 등 게임 밸런스 지표를 재현했다는 의미는 아닙니다. 실제 플레이어·수영·네트워크·밸브 활성화·출구 개방·아이템 생성 코드는 추가하지 않았습니다. 물 볼륨은 위치 정보이며 원형 침강부 Trigger는 외접 사각형이므로 후속 물 판정에서 반지름 조건을 함께 사용해야 합니다.

새 복사본을 생성하려면 `Tools > Indoor Pool v1.1 > Create Exact Map`을 사용합니다. 기존 편집 씬을 덮어쓰지 않고 새 씬·새 Generated 폴더를 만듭니다. 기본 파일을 검사하려면 `Validate Saved Map`을 사용하세요.

공유할 때는 기존 공통 3D Renderer와 라벨 도구도 필요하므로 `Assets`, `Packages`, `ProjectSettings`를 함께 전달하세요. 설계 문서를 바꾸면 구조화된 `Layout_v1_1.json`도 함께 갱신해야 생성 도구에 반영됩니다.
